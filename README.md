# SimBus | System Control Center

A robust business management and administrative dashboard built with **Laravel 11**, designed to streamline subscriber data, technical support tickets, and system health monitoring.

## 🚀 Features

### 🛠 Developer Control Center
- **System Health Monitoring:** Real-time tracking of Database connection, Storage permissions, and Environment status.
- **Ticket Management:** Dual-stream processing for Application Issues and Registration Requests.
- **Dynamic Status Logic:** Automated workflows for `Approve`, `Reject`, `Open`, and `Progress` statuses.

### 📊 Dashboard Analytics
- **Task Efficiency:** Integrated radial charts for visual progress tracking.
- **Live Statistics:** Instant counting of total tickets, resolved issues, and pending registrations.

### 🔐 Multi-Level Access
- **Developer:** Full access to system health and technical ticket handling.
- **Admin/Crew:** Access to operational data and customer management.

## 💻 Tech Stack

* **Framework:** Laravel 11 (PHP 8.2+)
* **Database:** MySQL
* **Frontend:** Blade Templates, Bootstrap 5, Bootstrap Icons
